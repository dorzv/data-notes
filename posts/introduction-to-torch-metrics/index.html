Introduction to Torch Metrics

Track your metrics while training a deep learning model using the TorchMetrics library.

Deep Learning
Machine Learning
Python
Author

Dor Zvulun

Published

April 26, 2024

Metrics are one of the most important parts of the deep learning field. When we train a deep learning model we need to track some metrics to understand if our model is good for the task. We also need metrics to compare two models and choose the better one.

There are a lot of metrics to use. If we think, for example, about image classification, we may want to know how accurate our model is. The accuracy metrics measure what is the proportion of times the model makes the correct prediction. In the classification case, we divide the number of correct classifications by the total images we try to classify.

Another popular metrics are the precision and the recall. Suppose we have a set of images and we want to classify them as “dog image” or “non-dog image”. Each classification result can be one of four:

  • True Positive (TP): The model predicts a “dog image” (the positive class) for an actual image of a dog (that is true).
  • False Positive (FP): The model predicts a “dog image” (the positive class) for a “non-dog” image (that is false).
  • True Negative (TN): The model predicts a “non-dog image” (the negative class) for an actual “non-dog” image (that is true).
  • False Negative (FN): The model predicts a “non-dog image” (the negative class) for an image of a dog (that is false).

The precision metric tells us the ratio between the true positive predictions to the total positive predictions the model makes (that means the true positive and the false positive.

\[\text{precision} = \frac{TP}{TP + FP} = \frac{TP}{\text{total positive predictions}}\]

The Recall metric tells us the ratio between the true positive predictions to the total real positive instances (the true positive and the false negative), which is the ground truth.

\[\text{recall} = \frac{TP}{TP + FN} = \frac{TP}{\text{total positive instances}} = \frac{TP}{\text{ground truth}}\]

As you can see, there are relatively simple formulas for the metrics we have seen so far, and that is true for most of the metrics, but why calculate these metrics by ourselves if there is a great library that does it for us?

TorchMetrics

TorchMetrics is a library by Lightning AI that works with PyTorch and helps us to calculate and track metrics. The library can handle a variety of metrics in different fields such as classification, clustering, detection, image, audio, text, and more. It also supports basic aggregation metrics such as mean, sum, minimum maximum, etc.

Using this library introduces several advantages over implementing the metrics by yourself, such as reducing boilerplate code and standardized interface and it can also help in distributed training. Moreover, if you use PyTorch Lightning, it has full integration with TorchMetrics (but of course you can use it with PyTorch).

Each metric in TorchMetrics implements three base methods:

  1. update() : update the state of the metric to include new information
  2. compute() : return the metric value based on the current state
  3. reset() : reset the metric to its initial state

The metrics inherit the torch.nn.Module so it has forward() method that lets us call the metric directly. In this case, it calls the update() method and returns the value for the current input only.

As always it will be clearer if we see an example of code, so let’s code it.

Let’s Code It

For the example, we will base on the PyTorch example of image classification on the MNIST dataset which can be found here.

We start by importing the necessary modules.

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torchvision import datasets, transforms
from torch.optim.lr_scheduler import StepLR

# import the metrics
from torchmetrics.aggregation import MeanMetric
from torchmetrics import Accuracy, Precision, Recall

and then defining the metrics.

single_epoch_mean_train_loss = MeanMetric()
single_epoch_mean_test_loss = MeanMetric()
accuracy = Accuracy(task="multiclass", num_classes=10)
precision = Precision(task="multiclass", num_classes=10)
recall = Recall(task="multiclass", num_classes=10)

For the loss, we use the mean metric to calculate the mean loss for each epoch over all the batches. We also define accuracy precision and recall metrics. Since we deal with a multiclass case with ten classes (the digits 0 to 9) we pass the arguments task="multiclass", num_classes=10 .

Now we define the network.

class Net(nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, 1)
        self.conv2 = nn.Conv2d(32, 64, 3, 1)
        self.dropout1 = nn.Dropout(0.25)
        self.dropout2 = nn.Dropout(0.5)
        self.fc1 = nn.Linear(9216, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.conv1(x)
        x = F.relu(x)
        x = self.conv2(x)
        x = F.relu(x)
        x = F.max_pool2d(x, 2)
        x = self.dropout1(x)
        x = torch.flatten(x, 1)
        x = self.fc1(x)
        x = F.relu(x)
        x = self.dropout2(x)
        x = self.fc2(x)
        output = F.log_softmax(x, dim=1)
        return output

and the training and test steps.

def train(model, device, train_loader, optimizer, epoch):
    model.train()
    for batch_idx, (data, target) in enumerate(train_loader):
        data, target = data.to(device), target.to(device)
        optimizer.zero_grad()
        output = model(data)
        loss = F.nll_loss(output, target)
        single_epoch_mean_train_loss.update(loss.item())
        loss.backward()
        optimizer.step()

    print(f'Train Epoch: {epoch} \tLoss: {single_epoch_mean_train_loss.compute()}')
    single_epoch_mean_train_loss.reset()
def test(model, device, test_loader):
    model.eval()
    test_loss = 0
    correct = 0
    with torch.no_grad():
        for data, target in test_loader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            loss = F.nll_loss(output, target)
            single_epoch_mean_test_loss.update(loss.item())
            pred = output.argmax(dim=1, keepdim=True).cpu()  # get the index of the max log-probability
            target = target.cpu()
            accuracy.update(pred, target.view_as(pred))
            precision.update(pred, target.view_as(pred))
            recall.update(pred, target.view_as(pred))

    print(f'Test - Mean loss: {single_epoch_mean_test_loss.compute():.4f}, ',
    f'Accuracy: {accuracy.compute():.4f}, Precision: {precision.compute():.4f} ',
    f'Recall: {recall.compute():.4f}')

    single_epoch_mean_test_loss.reset()
    accuracy.reset()
    precision.reset()
    recall.reset()

In the steps, you can see we update the states of the metrics while going over the batches, and after the loop, we compute the metrics values, print them, and finally reset them for the next time.

We don’t need to do any calculation. TorchMetrics does all the work for us.

Finally, we train the model, and during training we can see the metrics printed to the console.

    device = 'cuda' if torch.cuda.is_available() else 'cpu'

    torch.manual_seed(0)

    transform=transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.1307,), (0.3081,))
        ])
    dataset1 = datasets.MNIST('./data', train=True, download=True,
                       transform=transform)
    dataset2 = datasets.MNIST('./data', train=False,
                       transform=transform)
    train_loader = torch.utils.data.DataLoader(dataset1, batch_size=64, shuffle=True)
    test_loader = torch.utils.data.DataLoader(dataset2, batch_size=256, shuffle=False)

    model = Net().to(device)
    optimizer = optim.Adadelta(model.parameters(), lr=1.0)

    scheduler = StepLR(optimizer, step_size=1, gamma=0.7)

    for epoch in range(1, 15):
        train(model, device, train_loader, optimizer, epoch)
        test(model, device, test_loader)
        scheduler.step()

Conclusion

TorchMetrics is a powerful library to handle all your metrics during the training of deep learning models. It contains a very wide variety of metrics for different tasks, and each of them can be configured in several ways to help you get the exact metric you want to track.
